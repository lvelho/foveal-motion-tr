# Foveated Vision on a Moving Head: First Experiments

VISGRAF Lab technical note (Luiz Velho, with Claude), 12 November 2026. It covers the first phase of
[visgraf/foveal-motion](https://github.com/visgraf/foveal-motion): experiments M1 (the dolly) and M2 (range from the
head's motion), issues #1 and #3.

- `main.tex`: the note. Build with `pdflatex main.tex` twice (or Overleaf, pdfLaTeX).
- `techrep-ic.sty`: the VISGRAF technical-report cover, as in `lvelho/fov-render-tr`.
- `figs/`: figures copied from the records of visgraf/foveal-motion (`docs/runs/issue-1/`, `docs/runs/issue-3/`),
  at commit `9cf234b` (main after PR #4).
- `main.pdf`: the built note.

The report number on the cover (`\TRNumber` in `main.tex`) is a placeholder to confirm.
